# 台湾金牛论坛前端接入说明

## 1. 原站基准

- 原站视觉与模块结构基准：`frontend/Zz_www.kh6s.com/index.html`
- 当前静态承载页：`frontend/public/vendor/twjinniu/index.html`
- 结论：金牛站点首页不得自行重设计，必须以原站 DOM、原站蓝色主题、原站模块顺序、原站模块样式为准。

## 2. 必须遵守的首页规则

### 2.1 开奖结果模块

- 必须直接复用 `frontend/public/vendor/shengshi8800/kj/local.html`
- 必须同时提供三个彩种切换：
  1. `台湾彩`，`lottery_type=3`
  2. `澳门彩`，`lottery_type=2`
  3. `香港彩`，`lottery_type=1`
- 这条规则适用于所有站点，后续新站或改版站点也不得省略任意一个彩种。
- 若对应模块的 `mode_id` 未在文档中确认，必须先询问，不得自行推断或改接其他模块。
- 不允许再单独做站点私有开奖结果 HTML、私有倒计时逻辑或私有开奖接口。
- 首页开奖结果区只能在原模块容器里接入三彩种切换，不允许额外添加与原站风格不一致的自定义说明盒子、警告面板或重设计外框。

### 2.2 视觉规则

- 首页主色必须沿用原站蓝色体系：`#0a5cda`、`#0000ff`、`#0c35f5`
- 红色和黄色只用于命中、强调、标题描边等局部高亮
- 不允许把整站主导航、模块标题、主要容器改成红绿主题
- 如果 live 数据缺失，应直接落在原模块文案内提示，不要另起一套脱离原站样式的大提示块

## 3. 前端接口

### GET `/api/latest-draw`

统一开奖结果接口，供 `local.html` 使用。

查询参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `lottery_type` | 否 | `1=香港彩`、`2=澳门彩`、`3=台湾彩` |

返回重点字段：

| 字段 | 说明 |
| --- | --- |
| `current_issue` | 当前期号 |
| `draw_time` | 当前期开奖时间 |
| `result_balls` | 6 个正码球 |
| `special_ball` | 特码球 |

### GET `/api/next-draw-deadline`

统一倒计时接口，供 `local.html` 使用。

查询参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `lottery_type` | 否 | `1=香港彩`、`2=澳门彩`、`3=台湾彩` |

返回重点字段：

| 字段 | 说明 |
| --- | --- |
| `current_issue` | 当前期号 |
| `next_issue` | 下期期号 |
| `next_time` | 下期开奖时间 |
| `server_time` | 服务端当前时间 |

### GET `/api/vendor/article-detail`

文章详情接口，供 `/twjinniu/amgst/:articleId` 使用。

查询参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `article_id` | 是 | 文章 ID，如 `7701` |
| `lottery_type` | 否 | `1=香港彩`、`2=澳门彩`、`3=台湾彩`，默认 `3` |

说明：

- 优先读取本地 PostgreSQL 对应预测模块历史数据
- 对于已经确认映射的模块，如果当前彩种没有 live 数据，必须明确提示缺失，不能静默回退旧静态快照
- 历史文章 ID 如能按文章标题映射到当前 live 模块，也必须优先走本地 PostgreSQL，而不是直接回退旧静态快照
- 只有未映射文章或历史兼容场景才允许回退 `frontend/public/vendor/twjinniu/amgst/*.html`
- 详情页样式同样必须保持原站文章页风格

### GET `/api/twjinniu/site-page`

金牛站点聚合调试接口，供后续需要读取统一预测模块数据时使用。

查询参数：

| 参数 | 默认值 |
| --- | --- |
| `site_key` | `twjinniu` |
| `site_id` | `7` |
| `web_id` | `7` |
| `lottery_type` | `3` |
| `history_limit` | `8` |

说明：

- 这个接口是统一数据入口，不是重新设计首页布局的依据
- 首页视觉仍然必须以 `kh6s` 原站静态结构为准
